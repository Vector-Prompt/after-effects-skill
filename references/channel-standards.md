# Channel Standards & Windows AE 2026 Rules

## 1. Execution & ES3 Architecture
- **Categorized 1-Click `.jsx` Organization (`ae_templates/<Category>/`)**: Always save generated scripts into the appropriate category subfolder under `ae_templates/`—never dump scripts loosely in `ae_templates/` root, keeping root clean with only `_channel_helpers.jsxinc`, standard `.md` docs, and category folders:
  - `ae_templates/Text_Animations/` — kinetic typography, word reveals, typewriters, text animators
  - `ae_templates/UI_Animations/` — buttons, glowing rims, notifications, chat bubbles, Face ID, interactive UI controls
  - `ae_templates/Glass_And_3D_Cards/` — Liquid Glass, Glassmorphism, 3D card stacks, floating carousels
  - `ae_templates/SaaS_Explainers/` — multi-scene product explainers, flowcharts, dashboards, ad promos
  - `ae_templates/Reels_And_Shorts/` — `9:16` vertical Shorts/Reels compositions
  - `ae_templates/Camera_And_Rigging/` — camera rigs, null chains, voiceover/marker sync tools
  - `ae_templates/Utilities_And_Tests/` — plugin/effect diagnostics & helper tests
  Always start scripts inside category subfolders with `//@include "../_channel_helpers.jsxinc"` and run via **File > Scripts > Run Script File...** inside AE.
- **ECMAScript 3 Strict**: No `let`, `const`, arrow functions, template literals, or `JSON`. Always use `var` and string concatenation.
- **Re-fetch Property Refs After `addProperty()`**: Calling `group.addProperty(...)` invalidates previously stored sibling Property references inside that same `PropertyGroup`. Always add all sibling shapes/fills/strokes/effects FIRST, then grab child property references.
- **Safe Vector Group Access**: After renaming a Shape vector group, reference it by index `.property(1)` rather than `.property("ADBE Vector Group")`.
- **Safe Text Centering**: Set `fontSize`, `fillColor`, `font`, and `justification` on `textDoc` and call `textProp.setValue(textDoc)` BEFORE calling `sourceRectAtTime(0, false)`.
- **Critical Parenting Order**: Always set a child layer's local `Position` **AFTER** assigning `child.parent = masterNull` (otherwise AE converts pre-parent comp coordinates into shifted local offsets when `masterNull` isn't at `[0, 0]`).
- **Animate Parent Null `Scale` AFTER Parenting Children (AND Always Reset Child `Scale` & `Rotation`)**: Never set non-100% `Scale` keyframes on a parent Null at `t = 0` *before* parenting children to it—AE preserves world size by counter-scaling each child (e.g., `100 / 0.88 = 113.6%`), which makes child `_FrostBlur` / `_SpecularRim` outlines render noticeably larger than the card! Always animate `parentNull.Scale` *after* all children are parented, and explicitly reset `child.Scale = [100, 100]` (or `[100, 100, 100]`) and `Rotation = 0` right after `child.parent = parent`.
- **Child Opacity & `inPoint` Discipline**: In After Effects, `Opacity` is **not** inherited by child layers. Always set `inPoint` or animate `Opacity` directly on child layers (text, icons, bars) rather than only on their parent Null/Card.
- **3D Child Parenting Rotation Reset**: When parenting a 3D child to an already-rotated 3D parent card, explicitly reset `Orientation = [0,0,0]` and `X/Y/Z Rotation = 0` AFTER `child.parent = cardLayer`, set `Position = [dx, dy, -6]`, and avoid 2D effects (`CC Light Sweep`, `Drop Shadow`) directly on rotated 3D Shape Layers in Classic 3D.
- **Reverse-Loop Removal & Pre-Expression Reads**: When removing keyframes (`removeKey(k)`) or effects (`property(i).remove()`) in a loop, always iterate **downward** (`numKeys -> 1`) to prevent index shifting. Use `prop.valueAtTime(t, true)` to read the pre-expression keyframed/static value vs `(t, false)` for post-expression output; check `posProp.dimensionsSeparated` (`ADBE Position_0/_1/_2`) before setting Position; prefer `layer.id` (AE 22+) over fragile indices when tracking layers across reorders.
- **Silent Expression Errors & Locale-Safe Controls**: Assigning `prop.expression` never throws in ES3—verify via `safeSetExpr()` (`prop.canSetExpression` -> force `prop.valueAtTime(0, false)` -> check `prop.expressionError`) or `auditCompExpressions(comp)`. In expressions referencing `CONTROLS` Null sliders/colors, prefer parameter index `effect("Accent")(1)` or matchName `("ADBE Color Control-0001")` over localized display names like `("Color")`/`("Slider")`. Note `ADBE Layer Control-0001` takes an integer layer index in ExtendScript, while returning a Layer object in expressions.

## 2. Visual Quality & Finishing Rules
- **No QCA (`PEQCAGL`) on Light/Cream Backgrounds**: Never apply `QCA_Finishing` (`PEQCAGL` / Shift Channels) to light, white, or cream editorial compositions—chromatic aberration causes visible orange/cyan RGB fringing on dark text. Use `addQCAFinishing(comp, true)` **only** on dark/neon SaaS scenes.
- **Smooth Color-Shifting Border Glow (Zero Thin-Stroke Flicker)**: Never apply high-threshold `PEDG2` Deep Glow 2 directly onto thin (`2–3px`) moving/hovering strokes—sub-pixel movement causes distracting border flicker. Instead, use `addSmoothOrbitGlowBorder()` from `_channel_helpers.jsxinc` (orbiting `ADBE 4ColorGradient` + `ADBE Set Matte3` + `PEDG2` `Threshold = 0`) for silky-smooth, Apple-Intelligence-style rotating color-shifting rim glow!
- **Realistic Frosted Glass & 4-Color Gradient Cards (No Flat Linear Ramps)**: Avoid flat opaque 2-color linear `ADBE Ramp` fills on UI cards. Always give SaaS/Apple UI cards a realistic frosted-glass look using `addGlassCardEffect()` (backdrop `ADBE Box Blur2` Adjustment Layer + `TrackMatteType.ALPHA` + translucent `ADBE 4ColorGradient` surface + subtle `CC Light Sweep` + soft `ADBE Drop Shadow`).
- **No Unsolicited Floating Tapered Lines**: Do not add decorative thin flying Trim Paths lines across empty SaaS backgrounds unless explicitly requested; use `Fluid Liquid Mesh Gradient` (`4-Color Gradient + Motion Tile Mirror + Turbulent Displace Twist`) + `64x64` tech grid + soft glow auras.
- **Subtle Luxury Glass Shine**: For `CC Light Sweep` on dark UI cards, keep `Width: 220–260`, `Sweep Intensity: 12–16`, `Edge Intensity: 4`, and do not stack high-intensity `ADBE Glo2` after `CC Light Sweep`.
- **Never Squash Rounded Corners**: Never animate non-uniform `Scale` (`[100, 5]`) on rounded rectangles/pills. Always animate `ADBE Vector Rect Size` (`[w, h]`) or `X`/`Y` Slider Controls while keeping `Roundness` constant.
- **Vector Icons Over Unicode Glyphs**: Draw checkmarks, arrows, and UI icons using native `Shape` paths (`ADBE Vector Stroke Line Cap` = `2` for Round, `ADBE Vector Stroke Line Join` = `2` for Round — **never** `LineCapType.ROUND`, which is undefined in ExtendScript!) rather than Unicode text characters (`✓`), since display fonts like Bricolage Grotesque may lack symbol glyphs.

## 3. Channel Fonts & Installed GPU Plugins
- **Default Font**: **Bricolage Grotesque** (`headline800`, `sub600`, `body500`); **Recursive** as technical/code alternative. See `ae_templates/Channel_Fonts_Standard.md` and `applyChannelFont(td, role)` in `_channel_helpers.jsxinc`.
- **Cursive / Script Font Rule (Strict Single-Family)**: Whenever a user screenshot (`ss`) contains cursive/script text, select **ONE** matching font from `Luxurious_Script` (`"script_luxurious"` -> `LuxuriousScript-Regular`), `Sacramento` (`"script_sacramento"` -> `Sacramento-Regular`), or `Alex_Brush` (`"script_alex"` -> `AlexBrush-Regular`) in `H:\Youtube Channel\Fonts\`. **Never mix two or more cursive fonts in the same animation**—use ONLY the chosen single cursive font everywhere cursive appears in that animation.
- **External Assets (`Background / UI Elements / Icons`)**: When the user supplies separate paths for background images/textures/videos, UI element images, or icons, import each cleanly via `importExternalAsset(proj, path, folder)` and scale/fit smoothly rather than replacing them with placeholders.
- **Deep Glow 2 (`"PEDG2"`)**: Use `addGlow(layer, thresh, radius, intensity)` (falls back to `"ADBE Glo2"`).
- **Quick Chromatic Aberration 3 (`"PEQCAGL"`)**: Use `addQCAFinishing(comp, isDarkScene)` on dark scenes only.

## 4. Mandatory Defaults: Voiceover Markers, Animate-In/Out & Expressions
- **Voiceover-Ready Marker-Driven PreComp (`setupVoiceoverMarkers`)**: **ALL** generated `.jsx` animations MUST be built inside `Anim_PreComp` and wrapped in `Main_Voiceover_Sync` with `setupVoiceoverMarkers(preLayer, mainDur, markerEvents)` by default (unless the user explicitly asks for a single flat comp), so dragging any Layer Marker re-times that beat to match a voiceover.
- **Mandatory Symmetric Animate-In & Animate-Out (No Abrupt Ends)**: **Every** animated element, card, text block, badge, icon, and background layer MUST have **both** an **Animate-In** and a smooth **Kinetic Animate-Out** before `preDur` ends (or before leaving the scene). Never leave finished UI cards frozen until the last frame—reverse-stagger exits (2–5 frames per item), slide/tuck down or shrink gently (`Scale 100% -> 84–88%` or `addKineticOutro()`), spin/trim out, and fade `Opacity` cleanly to `0%` (making sure child layers like `_FrostBlur` / `_SpecularRim` / text / icons fade out too!).
- **Expression-Driven Realistic Motion (NEVER Static/Robotic)**: **ALL** generated `.jsx` animations MUST leverage expressions from `references/expressions-cookbook.md` alongside `85–88%` Easy Ease curves so motion feels organic, physical, and alive:
  - **Spring/Elastic Physics**: Use `bounceExpr()` (`decay` 6–12), Cinecom Squash & Stretch, or `Scale at Markers` on UI pills, icons, badges, and buttons.
  - **Living Micro-Motion**: Use gentle sinusoidal hover (`Math.sin(time * 1.5 + phase) * 6`), `noise()` drift, or subtle `Wiggle Loop` on floating cards/orbs so scenes never freeze dead during holds.
  - **Smart Procedural Links**: Use `createPath()` for dynamic node connectors, `length(cam, target)` for 3D Auto-Focus DOF, `sourceRectAtTime` for auto-sizing/auto-fit text, `toCompVec` Backface Hide on 3D flips, and universal comma counters.
  - **Asymmetric Speed-Graph Easing & Stagger Budget**: For snappy UI arrivals, prefer asymmetric easing (`setSmoothCurve(prop, 88, 18)` — fast `18%` launch out, long `88%` settle in) over flat `33%` `F9` or symmetric eases; scale long move durations via `base_ms * Math.sqrt(dist_px / base_dist_px)` and keep group stagger totals under `~800ms`.

## 5. Export, Render Queue & MOGRT Rules
- **Render Queue vs AME**: H.264 was removed from AE's native Render Queue (and MP4 cannot store alpha). Export **ProRes 4444** or **PNG Sequence (`RGB + Alpha`)** via `app.project.renderQueue`, and send **H.264 MP4** deliverables to Adobe Media Encoder via `app.project.renderQueue.queueInAME(false)`. Always include file extension in `om.file` and wrap `om.applyTemplate(...)` in `try/catch` (preset names vary per machine).
- **Essential Graphics (`.mogrt`)**: Only Checkbox, Color, single-value Slider, and Source Text can be exposed (`prop.canAddToMotionGraphicsTemplate(comp)` -> `addToMotionGraphicsTemplate(comp)`). Save the project before `comp.exportAsMotionGraphicsTemplate(...)`.

## 6. AE 26.x ExtendScript Traps & Hard-Won Fixes (Measured)
- **Forbidden Variable Names & Chained Ternaries**: ExtendScript reserves **`short`, `int`, `char`, `byte`, `long`, `float`, `double`, `boolean`** (`var short = ...` throws `Illegal use of reserved word` and aborts silently before line 1!). Also avoid chained ternaries (`a ? b : c ? d : e`) — ExtendScript ES3 misreads them; use `if/else` or lookup maps.
- **Open Viewer Last + Unviewed Rect Guard**: Keep `comp.openInViewer()` at the **end** of heavy scripts (an expression-heavy comp open in the viewer forces main-thread re-evaluation on every scripted change). On unviewed comps, `ADBE Vector Rect Size` `setValue()` can throw `invalid numeric result` even when the value landed—read back in `catch` or open viewer right after build.
- **Type & Property Lookups That Fail Silently**:
  - `layer instanceof AVLayer` is `false` for Shape/Text layers—probe `layer.property("ADBE Root Vectors Group") !== null` for Shapes, and `item.typeName` (`"Composition"`, `"Footage"`, `"Folder"`) for project items.
  - Use `ADBE Rotate Z` (or `layer.transform.rotation`, never `ADBE Rotation`), `layer.timeRemap`, and `layer.audioLevels`.
  - Set `td.tracking = 0` explicitly on Text layers so leftover Character panel tracking does not leak in; on AE 24+, resolve PostScript names via `app.fonts.getFontsByFamilyNameAndStyleName(family, style)`.
- **Shape Layer Quirks**:
  - Inside `Contents`, index 1 renders in **front** (build **front-to-back**), opposite the comp layer stack (`layers.add*` lands at index 1 = build **back-to-front**).
  - `ADBE Vector Graphic - G-Fill` / `G-Stroke` stops cannot be scripted (stuck black-to-white) — always use **`ADBE 4ColorGradient`** or **`ADBE Ramp`** effects instead.
  - `ADBE Gaussian Blur 2` has `Repeat Edge Pixels` (`-0003`) **ON** by default: set `-0003` to `0` on soft glow solids so edges don't clip hard (keep `1` on frosted glass adjustment layers).
  - Polystar `Type = 2` (Polygon) hides Inner Radius (`property is hidden`); `ADBE Vector Stroke Dash 1` throws hidden error (build dashes with small rect + **Repeater**); overlap touching shapes 10–20px to prevent AA seam flicker.
- **Time Remap & Track Matte**:
  - Never delete all keys from `timeRemap` (`while (tr.numKeys)` hides the property permanently)—edit the 2 default keys in place, and re-assert `outPoint` *before* `inPoint` after `timeRemapEnabled = true`.
  - `setTrackMatte()` / `trackMatteType` auto-disables the matte layer (`enabled = false`); re-enable if the matte is also visible artwork.
- **60fps Cinematic Motion Blur**: Enable `.motionBlur = true` on **every** moving shape, icon, badge, matte, text, and precomp layer (plus `shutterAngle = 360–540`, `shutterPhase = -180 / -270` at `60fps`) so snappy `90/16` asymmetric curves show visible velocity blur.
